# あったらちょっと便利そうなツール達

思いついた「あったらちょっと便利そう」を、小さなツールにして置いていくリポジトリです。

**ツールは必要に応じて追加していきます。** 今ある分がすべてではなく、これから増えていく予定です。

## ツール一覧

### 絵関連のツール

| ツール | 内容 | ファイル |
| --- | --- | --- |
| ドット絵メーカー | 画像を入れて好みを少し調整するだけで、ゲーム用のドット絵（ピクセルアート）に変換します。PNG / JPEG / WebP に対応し、複数枚の一括変換もできます。 | [`絵関連のツール/ドット絵メーカー.html`](./絵関連のツール/ドット絵メーカー.html) |

### 小説関連のツール

| ツール | 内容 | ファイル |
| --- | --- | --- |
| 人物マップ | 人物カードを書きながら、人物同士の関係を線でつなげます。関係の変化、お互いへの態度、2人の違いを記録でき、プロフィール画像も付けられます。マップは複数持て、データはブラウザに自動保存されます（書き出し・読み込みにも対応）。 | [`小説関連のツール/人物マップ.html`](./小説関連のツール/人物マップ.html) |

### テキスト関連のツール

| ツール | 内容 | ファイル |
| --- | --- | --- |
| TextDrop | Markdownやテキストを入力し、好きな拡張子のファイルとして保存できます。Markdownプレビュー、ダークモード、自動保存にも対応。 | [`テキスト関連のツール/TextDrop.html`](./テキスト関連のツール/TextDrop.html) |

### 人物マップでできること

- **人物カード**: 名前・よみ・役割・一言・色・設定項目（外見／性格／目的・動機／過去など。自由に追加）・メモ・**隠れた一面**・**プロフィール画像**（ファイル選択、またはカードへのドラッグ＆ドロップ）
- **関係の線**: カードのふちの丸い点から線を引く。何もない所まで引くと、つながった新しい人物ができる。関係の名前・種類・矢印の向きを設定。矢印はカードに被らず、ほかのカードも自動で避ける。線や荷札をつかんでドラッグすると**自由に曲げられる**（「まっすぐな線」への切り替えも可）
- **関係の詳細**（線を選ぶと右の欄に出る）:
  - **他人への態度**: AからB、BからAを別々に記録（一方通行も表現できる）
  - **他人との違い**: 価値観・能力・行動方針などの違いを、分類つきで何件でも
  - **関係の変化**: 「友人 → 信頼できる相手」のような変化を、きっかけ・影響とともに複数、順番つきで記録。変化パターンは例として選べ、自由に書き換えられる
- **人物カードから見る**: 関係ごとの態度・違い・変化の要約と、その人物が関わる変化記録の一覧（関係のデータを参照するだけで、人物側に重複保存しない）
- マップの切り替え、並べ直し、人物一覧と検索、元に戻す／やり直す、自動保存、`.json` の書き出し・読み込み

## 使い方

各ツールは基本的にHTMLファイル単体で動きます（補助ファイルを置く場合があります）。

- **ダウンロードして使う**: ファイルを保存して、ブラウザで開くだけです。
- **GitHub Pages で使う**: 下の手順で公開すると、ブラウザからそのまま開けます。

## GitHub Pages

次の URL で開けます。

```
https://skyvesmir.github.io/a-little-convenience-goes-a-long-way/
```

## ツールを追加するには

1. カテゴリのフォルダ（例: `絵関連のツール/`）に、ツールの HTML ファイルを置く
2. `index.html` の中ほどにある `SHELVES` に、ツールの情報を1件足す
3. この README の「ツール一覧」にも1行足す

カテゴリが新しくなる場合は、`SHELVES` に棚（`name` と `tools`）をもう1つ足します。トップページには、足した分だけ棚とカードが増えます。

## フォルダ構成

```
.
├── index.html          トップページ（GitHub Pages 用）
├── README.md           このファイル
├── 絵関連のツール/
│   └── ドット絵メーカー.html
├── 小説関連のツール/
│   └── 人物マップ.html
├── テキスト関連のツール/
│   ├── TextDrop.html
│   └── textdrop-favicon.svg
└── tests/
    ├── jinbutsu_map_e2e.py      人物マップのE2Eテスト
    └── fixtures/legacy-export.json   旧形式データ（互換性テスト用）
```

## テスト（開発者向け）

人物マップには、ブラウザを実際に動かして確認するテストがあります。

```
pip install playwright && playwright install chromium
python tests/jinbutsu_map_e2e.py
```
